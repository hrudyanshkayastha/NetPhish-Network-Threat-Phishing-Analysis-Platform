    Platform Architecture & Detection Engineering

    Detailed design specifications of the NetPhish deterministic security engine.

    1. Static URL Phishing Pipeline

    • Offline Lexical Parser: Decomposes URL scheme, host, port, path, query, fragment without outbound network transmission.
    • 15 Security Features: Evaluates IP hostnames, unencrypted transport, long URLs (>75 chars), deep subdomains (≥3), authentication keywords, URL shorteners, punycode/IDN, high-risk TLDs, special character density, and brand mismatch.
    • Deterministic Scoring: Transparent points accumulation mapped to LOW, MEDIUM, HIGH, CRITICAL.

    2. PCAP Traffic & Flow Engine

    • Scapy Capture Ingestion: Reads `.pcap` and `.pcapng` files offline, calculates SHA-256 integrity hash.
    • 5-Tuple Flow Aggregation: Combines packets into bidirectional `(src_ip, dst_ip, src_port, dst_port, protocol)` sessions.
    • Behavioral Heuristics: Horizontal/vertical port scan (≥10 unique ports), connection bursts (≥50 conns/10s), periodic beaconing ($CV \le 0.35$), ICMP burst (≥20 pkts/10s), non-standard ports, and DNS length/numeric anomalies.

    3. Multi-Source Correlation

    • Shared Indicator Matching: Links URL host IP with PCAP destination IP, URL domain with DNS queries, and URL hostname with HTTP Host headers.
    • Temporal Alignment: Identifies events occurring within a configurable $\pm 5$-minute sliding window.
    • Attack Graph Mapping: Tracks progression: `URL → DOMAIN → DNS → IP → FLOW → DETECTION`.

    4. Unified Risk Engine

    • Formula: $\text{Risk} = \min(100, \text{URL}(40) + \text{PCAP}(40) + \text{IOC Correlated}(15) + \text{Temporal Proximity}(15))$.
    • Zero Double-Counting: Normalizes overlapping signals to prevent inflated risk postures.
    • Audit Transparency: Every point is accompanied by rule IDs, evidence strings, and timestamps.
